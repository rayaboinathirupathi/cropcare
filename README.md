# CropCare AI — AI-Powered Crop Disease Detection and Treatment Assistant

**CropCare AI** is an enterprise-grade, mobile-first web application designed specifically for Indian farmers to identify crop diseases, evaluate microclimate agricultural risks, and receive strictly grounded, CIBRC-verified treatment protocols in **English**, **Telugu (తెలుగు)**, and **Hindi (हिन्दी)**.

---

## 🌾 Key Capabilities

1. **Multi-Modal Diagnostic Input**:
   - **Photo Capture & Upload**: Camera capture with client-side downscaling and server-side binary magic bytes validation (JPEG, PNG, WebP up to 10MB).
   - **Natural Language Symptoms**: Multi-lingual symptom matching with interactive extraction chips and follow-up diagnostic questions.
   - **Microphone & Voice**: Web Speech API integration in Telugu (`te-IN`), Hindi (`hi-IN`), and English (`en-IN`) with editable transcription preview.

2. **Grounded Agricultural Knowledge Engine**:
   - Condition hypotheses generated by multimodal AI (Google Gemini 1.5 Flash) or offline ICAR rule matching.
   - **Strict CIBRC Verification**: Chemical dosages, formulations, water volumes, and Pre-Harvest Intervals (PHI) are strictly pulled from verified official records and calculated deterministically.
   - **Interactive Unit-Aware Dosage Calculator**: Real-time calculations across Acres, Hectares, Guntas (0.025 Acre), and square meters, with 16L knapsack sprayer tank breakdown.

3. **Weather & Microclimate Risk Engine**:
   - Real-time weather data integration via Open-Meteo REST API.
   - Agronomic indices: Fungal Spore Spread Risk, Pest Surge Index, and Spraying Window Feasibility.
   - Automatic browser geolocation with manual Indian district and state fallback.

4. **Tri-Lingual Localization (i18n)**:
   - Full dictionary translation in English, Telugu, and Hindi across all 11 application views.
   - Text-to-Speech (TTS) audio narration for outdoor farmers who prefer listening.

5. **Security, Privacy & Compliance**:
   - Prompt injection defense sanitizing user inputs.
   - No private photos used to train AI models without consent.
   - Complete data erasure control on device.
   - Integrated Toll-Free Emergency Hotline: **Kisan Call Center (1800-180-1551)**.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v25)
- npm or pnpm

### Installation
```bash
# Clone the repository
git clone <repo_url>
cd farming

# Install dependencies
npm install

# Copy environment template
cp .env.example .env.local
```

### Configuration (.env.local)
```ini
# Google Gemini API (Optional - uses verified ICAR fallback engine if absent)
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-1.5-flash

# Supabase PostgreSQL (Optional - uses local session storage if absent)
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_anon_key_here

# Weather Provider
WEATHER_PROVIDER=open-meteo

# Admin Secret Key
ADMIN_SECRET_KEY=cropcare_admin_secret_dev_2026
```

### Running Locally
```bash
# Development mode
npm run dev

# Run automated Vitest test suite
npm test

# Run TypeScript typecheck
npm run typecheck

# Production build
npm run build
npm run start
```

## 📜 Agricultural & Legal Disclaimer

CropCare AI is an advisory decision-support assistant. While diagnostic hypotheses are cross-referenced with official agricultural databases (ICAR, CIBRC, and State Agricultural Universities), farmers must always inspect product labels on the container, comply with applicable statutory restrictions, wear appropriate personal protective equipment (PPE), and consult local Krishi Vigyan Kendra (KVK) officers before intensive chemical applications.
